# 랜드스케이프 MVP 기획서

담당 하종욱 · Unity 6.3 LTS · 2026년 11월 17일 회의 내용 반영

## 1. 목적과 범위

고정된 소형 엄폐물 아레나에서 AI가 사격 여부와 엄폐 이동을 학습할 수 있는 전투 환경을 제공한다. PPO 기반 1 vs 1을 우선 완성하고, 성능이 확보되면 MA-POCA 기반 3 vs 3으로 확장한다.

랜드스케이프 담당은 고정 시드로 생성한 지형·경계·엄폐물·접근 경로, 스폰 공간 검증 및 맵 평가 정보 제공을 맡는다. 이동·시야·사격·오토에임·보상과 학습 정책은 관련 담당자와 연결한다.

## 2. MVP 환경과 제작 기준

| 항목 | 적용 방향 |
|---|---|
| 맵 | 야외 고정 엄폐물 아레나. 참고 구성 활용 또는 직접 설계 중 제작 방식 결정 |
| 크기 | Unity 기본 Plane의 X·Z Scale 25 × 25 기준. 기본 Plane은 로컬 크기 10 × 10이므로 부모 Scale 1 기준 실제 바닥 크기는 250 × 250 Unity 단위 |
| 높이 기준 | Unity 기본 Cube의 Y Scale 50 기준. 기본 Cube 높이 1이므로 부모 Scale 1 기준 실제 높이 50 Unity 단위. 지형의 최소·최대 높이 및 기복 적용 방식은 별도 결정 |
| 청크 | 전체 맵을 X·Z 각 5등분해 5 × 5, 총 25개로 구성. 250 × 250 맵 기준 각 청크는 50 × 50 Unity 단위 |
| 바닥과 경계 | 고정 시드 Simplex Noise로 낮은 기복의 지형을 생성하고 외곽 범위를 구성하여 맵 이탈 방지 |
| 엄폐물 | 나무·벽·바위를 고정 배치하고 이동·시야·사격 차단 범위를 공동 확인. 건물 추가 여부는 검토 |
| 접근 경로 | 중앙 및 엄폐물 사이 통로 확보. 분석용 경로 ID와 구역을 고정 배치 |
| 스폰 | A·B 시작 위치를 지정하고 충돌·접근성 확인. 평가 시 시작 위치 교환 가능하도록 구성 |
| 캐릭터 여유 공간 | 실제 캡슐 크기·자세를 기준으로 통로와 스폰 공간 검증 |

고정 시드와 설정으로 Simplex Noise 지형을 생성하고 결과를 저장해 모든 경기에서 같은 지형을 사용한다. 기복과 높이 범위는 소형 아레나의 이동·엄폐 검증에 맞춰 조정한다. 엄폐물은 고정 배치한다. 엄폐물 개수·높이·간격·통로 폭·시야 범위는 이동과 사격을 연결한 뒤 확정한다. 수동 배치의 공정성은 가정하지 않고 시작 위치 교환 평가로 확인한다.

## 3. 전투 흐름과 환경 지원

기본 흐름은 중앙으로 이동 → 적 발견 시 교전 → 한쪽 사망 또는 제한시간 종료까지 반복한다. 제한시간은 5분이며 시간 초과 시 승패 판정 세부 규칙은 추가 결정한다. 아레나는 중앙 목표 위치, 엄폐 위치 후보 및 이동 가능한 경로를 제공한다. 이 흐름을 규칙으로 강제할지 정책이 선택하게 할지는 추가 결정한다.

적이 엄폐물 뒤로 사라졌을 때 마지막 관측 방향으로 접근하는 방식, 피격·근접 탄환 방향을 단서로 돌아보는 방식은 검토 사항이다. 맵의 전체 적 위치나 모든 탄환 정보를 관측으로 자동 제공하지 않으며, 감지 범위와 조건을 관련 담당자와 확정한다.

교착상태 대응과 피킹은 미확정이다. 피킹 채택 시 콜라이더 좌우 이동에 따른 벽 관통·캐릭터 겹침·사격 원점 문제를 공동 검증한다.

## 4. 전투 시스템과의 연결

조준은 전방 시야각 안의 오토에임을 사용하고, 탄약·재장전 기능은 제거한다. 엄폐물은 대상 탐지와 사격의 가림 판정에 사용하되, 전방 각도 안에 있다는 이유만으로 가려진 적을 자동 조준하지 않도록 연결한다.

랜드스케이프는 벽·엄폐물의 충돌체와 판정 레이어, 중앙 위치, 스폰 후보, 경로 구역 정보를 제공한다. 이동 담당과 통로·충돌을, 사격 담당과 탐지·사격 차단을, 학습 담당과 허용 관측·평가 기록을 합의한다.

## 5. 평가 지표와 기록

| 단계 | 평가 항목 |
|---|---|
| 1 vs 1 / PPO | 승률, 생존시간 및 대비 생존시간 비율, 엄폐 활용 교전 비율, 평균 가한·받은 피해량 |
| 3 vs 3 / MA-POCA | 팀 승률, 평균 생존시간, 엄폐 활용 교전 비율, 평균 가한·받은 피해량 |
| 보조 분석 | 고정 경로별 이용 비율. 기여도·어시스트 적용 검토, 협동 지원률 보류 |

승률은 승리 경기 수 ÷ 전체 평가 경기 수로 기록한다. 제한시간은 5분이며 무승부 판정과 시간 초과 시 승패 처리의 세부 규칙을 확정한다. 생존시간은 경기 시작부터 사망 또는 종료까지 기록하며, 종료 시 생존한 인원은 별도 표시한다. 대비 생존시간 비율의 비교 대상과 분모는 미정이다.

엄폐 활용 교전 비율은 판정 단위와 계산 기준을 확정한 뒤 산출한다. 후보는 엄폐 활용으로 판정된 교전 시간 ÷ 전체 유효 교전 시간이지만 확정식은 아니다. 위치·엄폐물 ID·가림·사격·피격 시각을 연결할 수 있는 기록을 준비한다. 교전이 없는 경기는 별도 처리한다.

협동 이득 비교는 공통 상대와 평가 조건을 먼저 정한다. 1 vs 1 PPO와 3 vs 3 MA-POCA는 인원수와 알고리즘이 동시에 달라지므로 승률 차이만으로 협동 효과를 단정하지 않는다.

## 6. 보상과 평가의 구분

경기 종료 시 결과 점수는 승리 +1, 패배 -1, 무승부 0으로 정산하며 소수점 부가 점수도 함께 정산한다. 생존시간 +0.1은 예시다. 초기 시험 후보는 가한 피해량 0.4, 받은 피해량 0.4, 무교전 약 -0.1, 첫 교전 시간 0.2, 회복시간 0.2 - α이며 각 부호·조건·계산식과 α는 미확정이다. 명중률 70~80%는 검토 기준이고 점수 확정값이 아니다. 시간 경과에 따라 보상을 줄이는 방안은 논의 단계다. 생존시간 지표와 시간 보상의 계산식은 별도 확정하며 랜드스케이프에서 임의 지급하지 않는다. 어시스트 상태 리스트와 기여도는 적용 여부·판정 기준을 정하고, 학습을 지연시키면 제외하는 방향을 검토한다.

## 7. 공간 및 판정 원리

- 지형 높이는 여러 주파수의 Simplex Noise를 가중 평균해 0~1로 정규화하고 설정된 높이 범위로 변환한다. 지형 경사와 충돌은 생성 결과를 기준으로 검증한다.
- 전방 시야각 후보 판정은 단위 전방 벡터 f, 적 방향 단위 벡터 d에 대해 `f·d >= cos(시야각/2)`를 사용한다. 거리와 가림 검사는 별도다.
- 시야 가림은 관측 원점부터 적의 지정 지점까지 유한 선분의 충돌로 확인한다. 사격 원점이 다르면 별도 사격 가림 검사가 필요하다.
- 엄폐물 근처에 있다는 사실과 적의 사격을 차단하는 엄폐 활용은 구분한다. 여러 적에 대한 판정과 부분 노출 기준은 평가 담당과 합의한다.
- 청크 좌표는 맵 시작점에서의 X·Z 거리를 각각 청크 너비·깊이로 나눈 뒤 내림해 계산한다. 맵 바깥과 최대 경계는 범위 밖으로 처리한다.
- 스폰 공간은 반지름 r, 높이 H인 캡슐의 양 끝 구 중심을 발 위치에서 r, H-r 높이에 두어 검사한다. `H >= 2r`이어야 한다.

## 8. 완료 기준과 개발 순서

1. 고정 시드와 설정으로 지형을 생성·저장하고 외곽·엄폐물·중앙 목표·A/B 스폰을 배치해 맵 버전을 부여한다. 동일 설정의 재생성 결과와 경기 간 지형 고정을 확인한다.
2. 실제 캐릭터로 스폰 겹침, 맵 이탈, 통로 막힘 및 중앙 접근을 확인한다. 이동 담당과 기존 경사 조건을 유지한 지형의 급경사에서 지면 꺼짐을 함께 검사한다.
3. 전방 오토에임의 가림 판정과 사격 차단을 연결해 1 vs 1 전투 반복을 확인한다.
4. 동일 맵·시작 조건으로 경기를 재설정하고 위치 교환 평가와 필요한 사건 기록을 확인한다.
5. PPO 성능 기준을 합의해 충족한 뒤 3 vs 3 및 MA-POCA를 검토한다.

기존 게임 베이스 목표 기간은 11월 23~29일이다. 변경 범위에 따른 세부 일정과 학습 성능 통과 기준은 재확정한다.

## 9. 후속 확장 및 미확정 사항

고정 맵에서 학습 성능이 빠르게 확보되면 시드를 변경하는 랜덤 랜드스케이프로 확장한다. 전환할 성능·속도 기준은 팀에서 정하고, 확장 시 스폰·접근성·엄폐물 배치와 경로 구분 및 평가 기준을 다시 검증한다. 고지대·경사 경로 비교와 이동 제약 구역은 후속 검토한다.

실제 전투 영역의 사용 범위·제작 방식·엄폐물 배치, 스폰 규칙, 제한시간 종료 시 승패 판정, 피킹, 교착 대응, 엄폐 활용 판정, 시간 보상, 어시스트, 협동 비교 조건은 미확정이다.

## 10. 지형 통합 및 시험 조건

나무·벽·바위가 이동·시야·사격을 가리는 방식을 담당자와 확인한다. 건물은 추가 여부 미정이며 추가 시 첫 교전 시간과 보상 기준을 함께 재검토한다. 급경사에서 캐릭터의 지면 꺼짐과 지형 충돌을 이동 담당과 확인하고 현재 경사 조건은 유지한다. 경사별 시험 위치와 결과를 남긴다.

사격 담당은 캡슐 기준 머리·몸통 판정과 측면 총 배치를 검토한다. 지형 담당은 엄폐물의 가림과 총구 주변 충돌을 함께 확인하며 부위별 피해량·경계는 미정이다. 캐릭터 회전 수정의 구체적 내용은 이동 담당과 결정한다.
