# OutdoorArena Team A/B 수치 데이터 테스트 기록

2026-11-24 · Unity Game 뷰 · 4배속

로컬 OutdoorArena에서 원본 A/B 두 팀에 사거리 75 m, 명중 확률 25%, 수평 시야각 75°, 평지 걷기 5 m/s, 질주 8.125 m/s, 앉기 2.5 m/s, 몸통 피해 10, 머리 피해 20을 임시 적용했다. 시드 1301~1304를 사용하고 같은 시드의 A/B 사격 난수 배정을 바꿔 총 8회 실행했다. 고정 경유점을 순찰하고, 총구에서 적까지의 사격선이 막히면 이동을 이어갔다. 시간은 게임 내 시간 기준이며 강화학습은 실행하지 않았다.

같은 사거리·명중 확률의 배치 재검증에서는 75°가 A:B 8:24, 평균 53.87초였고 90°는 16:16, 평균 50.96초였다. 각 설정을 32회 검증했다. 이번 8회에서도 75°에서 장거리 명중과 제한 시간 이내 종료를 확인했다. 스폰별 승수는 고정 경로와 사격 규칙을 적용한 결과이며, 머리 피해 20의 동작은 이번 표본에서 관측할 기회가 없었다.

## 반영 후 검증

- 로컬 Unity MCP Play Mode에서 두 원본의 적용값과 팀·액터 ID 1/2, 이동·무기 준비 및 환경 준비 상태를 확인했다.
- 공개 씬 복사본의 Unity 배치 Play Mode에서 두 원본의 설정, 스폰 간 NavMesh 경로, 입력 브리지 이동 5.62 m를 확인했다.
- 공개판의 약 60 m 직선 검증에서 몸통 59.04 m에 피해 10, 머리 59.19 m에 피해 20이 적용됐다. 머리는 검증 중 목표 부위를 지정했으며, 저장된 자동 머리 조준 확률은 0이다.

## develop 공개판 추가 확인

- 두 스폰에서 중앙까지 완전한 NavMesh 경로를 확인했고, 씬이 엄폐물 128개를 등록했다.
- Team A 이동 입력으로 5.62 m 이동했고, F8 수동 모드 전환 함수로 수동 모드 진입과 카메라 복귀를 확인했다.
- 순찰 1대1은 추가 확인에서 제외했다. 직전 순찰 확인에서는 경유점의 NavMesh 연결 단계에서 경기가 시작되지 않았다.
- Unity 배치 에디터에서 검색 인덱싱 예외가 한 건 기록됐으나 기능 검증은 완료했다. 물리 키 입력과 사다리 등반은 이번 확인 범위 밖이다.
